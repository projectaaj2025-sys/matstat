# Инструменты сборки

## `build_kit.py`

Пересобирает автономный комплект `СтатПрактикум — комплект.7z`. Внутрь всегда
кладётся **свежая копия** корневого `index.html` под именем
`СтатПрактикум.html` — чтобы в архиве никогда не оставалась устаревшая сборка
приложения. Инструкции RU/EN/KK и обзор версии берутся из папки
`СтатПрактикум — комплект/`.

```bash
python3 -m pip install py7zr     # один раз
python3 tools/build_kit.py
```

## `test-solution-gate.mjs`

Регрессионная сюита на jsdom: проверяет правило показа разборов (верный ответ,
порог попыток, ползунок учителя), переводы новых строк, устойчивость к старым
записям проверок из версий 3.6–3.7, порядок запуска (`spBoot()` до первой
отрисовки) и дымовой проход по всем маршрутам приложения.

```bash
npm install jsdom                # один раз
node tools/test-solution-gate.mjs                       # корневая сборка
node tools/test-solution-gate.mjs "путь/к/СтатПрактикум.html"   # копия из архива
```

Сюита принимает путь к любому HTML-файлу сборки, поэтому одной командой
проверяется и `index.html`, и копия приложения из 7z-комплекта.
