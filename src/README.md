# Исходники веб-приложения

Приложение по-прежнему публикуется одним автономным `index.html`: материалы,
шрифты и вендорные библиотеки остаются встроенными, поэтому страница работает
без сети. Поддерживаемые CSS и код приложения хранятся отдельно:

- `css/` — стили в том же порядке, что и в HTML;
- `js/` — части приложения, соединяемые в указанном порядке в один classic
  script: навигация, задания, переводы, лабораторные работы, библиотека,
  материалы и новые функции курса. Глобальные функции нужны обработчикам
  событий и сохранены намеренно. Порядок берётся из `JS_PARTS` в
  `tools/build_site.py` и заканчивается файлом запуска `26-boot.js`:
  `24-ai-assistant.js` отвечает за провайдеров, запросы и панель помощника,
  `25-ai-studio.js` — за генерацию задач, их карточки и проверку ответов.

## Изменение CSS или JavaScript

1. Редактируйте файлы в `src/css/` или `src/js/`, не соответствующие блоки в
   сгенерированном `index.html`.
2. Соберите страницу: `python3 tools/build_site.py`.
3. Проверьте, что артефакт соответствует исходникам:
   `python3 tools/build_site.py --check`.
4. Запустите полный регрессионный прогон: `npm run test:all`.

Сборщик заменяет только блоки `style`/`script`, помеченные ID, и сохраняет
остальную страницу без изменений. Большие встроенные данные курса и сторонние
библиотеки пока остаются в `index.html` — они не дублируются в `src/`.

## Ключ сайта для Gemini

Статическая сборка никогда не содержит ключ сайта. Необязательный сервер
`tools/serve_ai.py` читает `AI_GEMINI_API_KEY` из окружения или локального
`.env` и проксирует запросы Gemini с того же origin. Без сервера доступен
прежний режим с личным ключом браузера; подробности — в `tools/README.md`.
