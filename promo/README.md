# Видеообзор СтатПрактикума

Актуальный ролик: **`statpracticum-overview-ai-ru.mp4`**. Для загрузки через интерфейсы, которые не открывают MP4 напрямую, подготовлен архив **`statpracticum-overview-ai-ru.zip`** с совместимой версией видео 1280×720.

- формат основной версии: MP4 (H.264 + AAC), 1920×1080, 24 кадра/с;
- язык титров: русский;
- длительность: 65 секунд;
- стиль: реальный интерфейс в окне браузера, тёмная информационная панель и главы;
- звук: без озвучки; добавлена техническая бесшумная AAC-дорожка для совместимости с видеоплеерами.

## Что показано

Ученику: теория, практика с автоматической проверкой, лаборатории, PISA на реальных данных, собственный проект, банк задач, поиск, тренажёр, контрольная, прогресс и ИИ-наставник.

Учителю: профиль проверки, число попыток и автооценка, готовый план урока, рабочие листы, загрузка собственных материалов и библиотека. В финале показаны автономная работа и интерфейс на русском, английском и казахском языках.

## Подключение ИИ по API-ключу

Отдельный блок показывает выбор провайдера и модели, ввод API-ключа и проверку подключения. Упомянуты DeepSeek, OpenAI, OpenRouter, Groq, Gemini, Mistral, Ollama и LM Studio.

Ключ хранится только в `localStorage` браузера, не включается в файл курса, а запрос отправляется непосредственно выбранному API-провайдеру. Для класса рекомендуется отдельный ключ. Подключение необязательно: без внешнего ключа остаётся локальный режим помощника.

## Как пересобрать

Для захвата требуется локально открытый сайт на порту 4173, `puppeteer-core` и `@sparticuz/chromium`. Для монтажа используются Pillow и `imageio-ffmpeg`.

```bash
npm install --no-save --package-lock=false puppeteer-core@25.14.0 @sparticuz/chromium@153.0.0
python3 -m venv .venv
.venv/bin/pip install Pillow imageio-ffmpeg
python3 -m http.server 4173 --bind 0.0.0.0
LD_LIBRARY_PATH=/tmp/al2023/lib node promo/capture_screens.mjs
.venv/bin/python promo/make_video_v2.py
```

Папки `_screens`, `_render_v2` и `_review_v2` содержат воспроизводимые промежуточные материалы и не добавляются в Git.
