# Видеообзор СтатПрактикума

Готовый ролик: **`statpracticum-overview-ru.mp4`**.

- формат: MP4 (H.264 + AAC), 1920×1080, 24 кадра/с;
- язык титров: русский;
- длительность: около 76 секунд;
- стиль: запись реального интерфейса с анимированными титрами и указателем;
- звук: без озвучки; добавлена техническая бесшумная AAC-дорожка для совместимости с видеоплеерами.

## Что показано

Ученику: теория, практика с автоматической проверкой, лаборатории, PISA на реальных данных, собственный проект, рефлексия, поиск, тренажёр ошибок, контрольная, прогресс и ИИ-наставник.

Учителю: профиль проверки, показ решений и число попыток, план урока, рабочие листы, загрузка своих материалов, библиотека, конспекты и экспорт автономной копии курса. В финале показаны офлайн-режим и интерфейс на русском, английском и казахском языках.

## Как пересобрать

Для захвата требуется локально открытый сайт на порту 4173, `puppeteer-core` и `@sparticuz/chromium`. Для монтажа используются Pillow и `imageio-ffmpeg`.

```bash
npm install --no-save --package-lock=false puppeteer-core@25.14.0 @sparticuz/chromium@153.0.0
python3 -m venv .venv
.venv/bin/pip install Pillow imageio-ffmpeg
python3 -m http.server 4173 --bind 0.0.0.0
LD_LIBRARY_PATH=/tmp/al2023/lib node promo/capture_screens.mjs
.venv/bin/python promo/make_video.py
```

Папки `_screens` и `_render` содержат промежуточные материалы. Сценарий и тексты титров находятся в `make_video.py`.
